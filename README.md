# School SMS Broadcast System

A full-stack application for sending SMS announcements to parents and students via Telegram.

## Features

- 📱 Send announcements to all sections or specific sections
- 📢 Telegram channel integration (FREE!)
- 📝 Quick templates (No Classes, Suspension of Classes)
- 📊 Modern dashboard with stats
- ✅ Broadcast history tracking
- 🔐 Admin authentication

## Tech Stack

### Backend
- Node.js + Express
- MongoDB with Mongoose
- Telegram Bot API
- JWT Authentication

### Frontend
- React.js
- Tailwind CSS
- Vite

## Deployment

### Prerequisites
- Node.js 18+
- MongoDB
- Telegram Bot Token
- Telegram Channels
